Торговый бот · API биржи

Бот для торговли на бирже с панелью управления

Программа торгует по заданному алгоритму через API биржи: ставит сетку ордеров, пересчитывает цель при каждой докупке и закрывает позицию по достижении уровня. Все параметры настраиваются в панели, без правки кода, а история сделок и логи видны в реальном времени. Работает с несколькими счетами одновременно.
